# Narlume · Windows 更新

Narlume 是面向小说作者的本地桌面创作工具，原名“生枝”。本仓库用于分发 Windows 安装包与软件更新文件。

## 下载

打开[最新正式发布](https://github.com/AureliaKae/1/releases/latest)，下载 `Narlume-Setup-<版本>.exe` 后安装。已有作品、历史与模型连接配置保存在本机原有目录。

0.3.1 及更早版本需先手动安装 0.3.2。从 0.3.2 起，可在“作品与设置 → 软件更新”中检查、下载，再保存并重启安装。

## 更新文件

每个正式发布包含 Windows x64 安装包、`.exe.blockmap`、`latest.yml` 及 `SHA256SUMS.txt`。请勿仅下载更新清单，它由客户端读取。

源码仓库：[AureliaKae/Narlume](https://github.com/AureliaKae/Narlume)（私有，需访问权限）。
